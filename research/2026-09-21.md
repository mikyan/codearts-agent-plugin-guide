## 许可证与安全审查

- Agentic Awesome 代码/工具为 MIT，原创非代码内容为 CC BY 4.0；所选镜像 frontmatter 逐项声明 MIT 和原始许可证来源。
- 10 个候选目录都只有一个 `SKILL.md`，没有 manifest、锁文件、 install/postinstall、二进制、下载器或遥测代码。安装只复制固定目录，没有执行正文命令。
- `geo-prospect` 的完整工作流会在 `~/.geo-prospects` 持久化联系人和商业信息；本轮拒绝文件、网络与命令权限，只用合成记录测试只读 pipeline。
- `career-ops` 的完整运行时可扫描招聘门户、处理履历与申请；镜像明确为 docs-only，本轮没有读取个人资料、访问门户、发送消息或提交申请。
- `geo-report-pdf` 的正文只给出 macOS Pandoc/Chrome 路径，且 docs-only 镜像没有模板/CSS；本机也没有 Pandoc 或 Chrome 命令，因此不执行任何生成命令。
- `interview-me` 的 Loading Constraints 明确禁止 CI、scheduled run 和 autonomous loop。本任务正是定时自动化，故未安装、未调用。

CodeArts 使用只存在于验证子进程内的非秘密 AK/SK 占位值配合显式外部模型；没有持久化或打印凭据。每次调用使用独立 `KERNEL_DATA_DIR`，拒绝 Edit、Write、Delete、Bash、Read、Glob、Grep、Web、浏览器和外部目录访问。项目 B 与项目 A 不共享安装目录；个人级从没有项目同名覆盖的目录调用。

## 安装、发现与回滚方法

每个已执行候选都从固定只读来源复制到作用域专属 `vendor/agentic-awesome-<name>`，再把完整候选目录复制到 CodeArts 原生 `skills/<name>`。没有运行 npm 或上游正文命令，也没有修改用户根 `package.json`、`codearts_cli.json`、持久权限或凭据。

每个作用域先运行真实 `codearts debug skill`，把 JSON 按候选名和准确 `SKILL.md` 绝对路径要求唯一匹配；随后运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`。删除准确 Skill/vendor 目录后再次运行诊断，要求原 `name + location` 为零。
