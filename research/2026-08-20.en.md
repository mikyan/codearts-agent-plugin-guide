## Environment and method

- Clean `mikyan/codearts-agent-plugin-guide` checkout at pre-run HEAD `75e164df181f001ec80bdc1106a27e0d8cefd777`, fast-forward checked against `origin/main`.
- Windows 11 Pro Build 26200; PowerShell 7.6.5; Git 2.53.0.windows.2; Node 24.14.1; npm 11.11.0; Python 3.14.3.
- Real CodeArts CLI 26.8.1 at `C:\Users\AI_BA\.codeartsdoer\installers\codearts.cmd`; model `mimo/mimo-v2.5`.
- Existing provider credentials were not read or logged. Nonsecret AK/SK placeholders only satisfied this machine's CodeArts preflight.
- The repository compatibility skill and its referenced decision ladder were followed. Deep upstream directories were copied to native `.codeartsdoer/skills/<name>` without their parent hierarchy.
- Each allowed candidate was freshly installed in project A, a second clean project B, and user scope from a consumer with no project override. `codearts debug skill` proved the exact source; independent `codearts run --format json --sandbox` events proved invocation.
- User source lived under `~/.codeartsdoer/vendor/<slug>`; the user-root `package.json` was never changed. Its SHA-256 stayed `589A2F93D6B401FCCE4EDED58C4C477C3891C3B580796862C58ACB4E5D73A4E7` before and after every candidate.
- Rollback removed only the candidate skill and vendor, followed by a discovery check. Temporary evidence is excluded from Git.

The [official CodeArts CLI Skills documentation](https://support.huaweicloud.com/intl/en-us/usermanual-cli/codeartsagent_cli_0019.html), updated 2026-07-27, documents project and user skill directories and project priority. CLI 26.8.1 did not behave consistently with that collision statement locally, so every guide requires one scope only.

## Security review

The five passing selections were content directories: ab-testing (MIT, 4 files/34,491 B), API design (MIT, 6 files/41,045 B; its Python template was not executed), team communications (MIT, 5 files/14,181 B), Khazix writer (MIT, 3 files/54,112 B), and guidelines advisor (CC-BY-SA-4.0, 6 files/31,468 B). No npm, lifecycle, binary, runtime-network, credential, or telemetry step ran.

The remaining findings were decisive: critique requires HTML output; planning-with-files contains 29 helper/hook files and depends on persistent writes plus host-specific commands; diagram-design has 195 files and requires HTML output; baoyu's `autocorrect.ts` invokes unpinned `npx autocorrect-node --fix` and its skill suggests unpinned Bun; dot-skill requests collaboration-platform secrets/OAuth, message writes, and private-chat/document collection. All executable third-party paths were read before use; blocked paths were not executed.
