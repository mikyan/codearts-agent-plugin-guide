## 结论摘要

本批实际推进 10 个此前未按该 slug 覆盖的候选：`animation-performance`、`animation-vocabulary`、`apple-design`、`ask-sonner`、`find-animation-opportunities`、`mobile-native`、`pick-ui-library`、`remove-animations`、`show-the-change` 和 `write-swift`。固定来源为 Agentic Awesome `v20.4.0` / `1519f8199eb73d110ebc01f309e26c1868c8d502`。

十项都在项目 A、全新项目 B 和个人级三个范围独立完成源文件哈希比对、CodeArts 唯一发现、真实 `codearts run`、精确卸载和卸载后发现检查：30/30 安装、30/30 发现、30/30 回滚通过。但 30/30 次 `mimo/mimo-v2.5` 调用都在任何 `skill` 或其他工具事件前返回 `400 Unsupported model mimo-v2.5`；`mimo/mimo-v2.5-pro` 的独立探针也在工具事件前被网络策略阻止。

因此十项均为 **Untested（环境阻塞）**，不是“不兼容”结论。本轮不新增 `guides/` 或指南索引。

## 环境与隔离方法

| 项目 | 值 |
| --- | --- |
| CodeArts CLI | 26.8.1；真实二进制 `C:\Users\AI_BA\.codeartsdoer\installers\bin\codearts.exe` |
| 系统 | Windows 11 Pro，Build 26200 |
| Shell / 工具 | PowerShell 7.6.9；Git 2.53.0.windows.2；Node 24.14.1；npm 11.11.0 |
| 模型 | 正式批次 `mimo/mimo-v2.5`；独立探针 `mimo/mimo-v2.5-pro` |
| 固定来源 | Agentic Awesome `v20.4.0` / `1519f8199eb73d110ebc01f309e26c1868c8d502` |

对每个候选逐一执行：

1. 项目 A：复制固定候选目录到 `<A>/.codeartsdoer/skills/<候选>`，逐文件核对 SHA-256，运行 `codearts debug skill` 和候选专用 `codearts run -m mimo/mimo-v2.5 --format json ...`，删除精确目录，再做卸载后发现检查。
2. 项目 B：从全新空目录重复完整流程，不复用项目 A 的安装或事件。
3. 个人级：确认没有项目同名覆盖后，复制到 `C:\Users\AI_BA\.codeartsdoer\skills\<候选>`，从独立干净目录重复发现、调用与回滚。

个人级测试没有修改用户根 `package.json`、`codearts_cli.json` 或持久权限文件。
