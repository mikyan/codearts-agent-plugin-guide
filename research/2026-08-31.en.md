## Upstream, discovery sources, and safety review

- Candidates came from the [GitHub Agent Skills topic](https://github.com/topics/agent-skills) and the active, popular [mattpocock/skills](https://github.com/mattpocock/skills) repository. The 2026-08-31 snapshot recorded 242,450 stars, 20,611 forks, 443 open issues/PRs, and a latest push on 2026-08-24. The pin is commit `6654f6b60cd9d5be8b54c6fafe44346dabeb3b76`, latest release `v1.2.3`, MIT.
- The first nine are content-only Skills. Only the pinned candidate directories and explicit local dependency directories were copied. No upstream root manifest, installer, binary, telemetry, network, or credential flow ran.
- Dependency closures were `implement + tdd + code-review`, `loop-me + grilling`, and `retro + writing-for-agents`. Every other candidate copied its complete directory and local references. Deep `skills/engineering`, `skills/in-progress`, and `skills/productivity` parents were not reproduced in CodeArts targets.
- `retro` may inspect machine session logs; this run restricted it to the candidate-local `session-log.md`. `teach` normally searches for trusted external sources; the run made `sources/http-status.md` the only source and prohibited network access. `prototype` was forbidden from opening a browser.
- `setup-pre-commit` instructs the agent to install unversioned `husky lint-staged prettier`, then run `npx husky init` and `npx lint-staged`. Its candidate directory supplies neither fixed package versions nor a lockfile. Under the requirement to pin dependencies and disable unaudited lifecycle scripts, it was not installed, loaded, or invoked; no low-quality substitute was used to fill the batch.
