## 许可证与安全审查

- 8 个候选目录只有 `SKILL.md`；`async-python-patterns` 与 `auth-implementation-patterns` 各另含一个 Markdown playbook。全部固定目录已完整审阅并生成源文件 SHA-256 清单。
- 候选目录没有 manifest、锁文件、install/preinstall/postinstall、可执行脚本、二进制、下载器或候选级遥测。没有运行上游仓库自己的 npm 脚本。
- 上游代码与工具为 MIT；原始非代码内容默认遵循 `LICENSE-CONTENT` 的 CC BY 4.0，6 个 v18.3.0 新增项 frontmatter 另声明 MIT。第三方来源声明仍优先。
- 聊天分析与 OneRoster 只使用内联合成数据；没有读取真实聊天或学生记录。API/鉴权只审查虚构路由；没有扫描服务、使用令牌或联网。DALI、EOL、Marlin 只生成只读计划；没有连接硬件或发送控制命令。ESL 没有访问零售系统或下发价格。
- 安装仅复制固定候选目录到 CodeArts 原生 `.codeartsdoer/skills/<name>`，并保留独立可删除的 `vendor/agentic-awesome-<name>`。没有更改用户根 `package.json`、`codearts_cli.json`、持久权限或凭据。

## 安装、发现、调用与回滚方法

每个候选分别执行以下流程，任何一项证据都不复用于其他候选：

1. 将固定目录复制到作用域内独立 vendor，再复制为 `.codeartsdoer/skills/<name>`；遇到同名路径即停止。
2. 运行真实 `codearts debug skill`，要求候选名称和准确 `SKILL.md` 绝对路径唯一匹配。
3. 运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`；提示包含完整合成输入与禁止工具边界。
4. 从 JSONL 记录目标 Skill、其他工具事件、call ID、最终文本和退出状态；人工核对核心断言。
5. 在第二个全新项目从零重复；个人级从没有项目覆盖的独立目录重复。
6. 删除前验证目标绝对路径位于对应 `.codeartsdoer` 根内，只删除准确 Skill 和 vendor；再次运行真实发现诊断并核对用户文件基线哈希。
