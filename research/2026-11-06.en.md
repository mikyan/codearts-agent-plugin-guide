# 2026-11-06: Ten Agentic Awesome v20.6.0 CodeArts validations

[中文](2026-11-06.md)

## Summary

This batch advanced ten candidates not previously covered under these slugs: `time-machine-recovery`, `minicut-film-studio`, `lurkapi-ad-research`, `antigravity-maintainer-batch-release`, `bash-defensive-patterns`, `figma`, `hyperframes-registry`, `netapi`, `postel-writing`, and `remotion-to-hyperframes`. The aggregate source was pinned to Agentic Awesome `v20.6.0` at `739c841480587361c3cb2047f5b34cdca69a0623`.

The safety review excluded the first four before installation: they respectively require macOS backup deletion, a closed-source installer and paid generation, credentials plus metered API calls, or maintainer publication privileges. The other six independently completed pinned-source hash comparison, unique CodeArts discovery, a real `codearts run`, exact removal, and post-removal discovery in project A, fresh project B, and user scope: 18/18 installations, 18/18 discoveries, and 18/18 rollbacks passed.

However, all 18 `mimo/mimo-v2.5` calls returned `400 Unsupported model mimo-v2.5` before any `skill` or other tool event. An independent `mimo/mimo-v2.5-pro` probe also returned 400. The six installed candidates are therefore **Untested (environment blocked)** and the four excluded candidates are **Untested (safety/platform blocked)**, not incompatibility findings. No `guides/` entry or guide index row was added.

- `package.json`: `589A2F93D6B401FCCE4EDED58C4C477C3891C3B580796862C58ACB4E5D73A4E7`

- Persistent permission file: `AC7831CD9D9FB18023BFD6C7778E71FF4A0DBCADAE60948189FBB0ECFDE2F447`

No candidate passed every “actual installation + CodeArts load + core invocation + clean second-environment reproduction + rollback” gate, so no formal guide was created. The six environment-blocked candidates require a complete rerun after model routing recovers. The four safety/platform-blocked candidates additionally need a real applicable platform or isolated test account, explicit write/cost authorization, and auditable dependencies; this static safety result cannot be promoted to compatibility.
