## Discovery and pin

- On 2026-09-14 the run checked GitHub Agent Skills Topics, active collections, releases, commits, issues, docs, and current CodeArts Skills, commands, and permissions documentation. GitHub Topics showed about 22,438 `agent-skills` repositories.
- Agentic Awesome had about 46.3k stars and 6.7k forks. GitHub showed v17.2.0 released on 2026-09-13 at commit `2fce708`, a 2,121-Skill catalog, and zero open issues and pull requests.
- None of the ten candidates appeared in earlier research. They were selected for usefulness, read-only representative value, Windows feasibility, fixed provenance, and bounded execution risk.
- AAS `LICENSE-CONTENT` applies CC BY 4.0 to non-code content without a more specific upstream notice. `tool-design` points to an MIT original repository, and `api-designer` declares MIT in frontmatter. Other content was studied only as a pinned compatibility subject and was not republished.
- Official CodeArts documentation confirms project `<project>/.codeartsdoer/skills`, user `~/.codeartsdoer/skills`, project-first same-name precedence, `codearts debug skill`, and `codearts run --format json --model`. The permissions page was updated 2026-09-10.

## Security review and installation

Each pinned candidate directory contained exactly one `SKILL.md`, with no package manifest, lockfile, install/postinstall, binary, downloader, or telemetry code. Every file was read before execution. Tests used synthetic inline text and did not execute npm, network access, production probes, edits, sub-agents, or external-service suggestions from the bodies. The remote image in `react-patterns`, npm suggestions in `software-architecture`, and external references in `tool-design` were not accessed.

Each scope cloned a separate sparse checkout from the fixed local mirror to `vendor/agentic-awesome-<name>` and copied only `skills/<name>` into native `.codeartsdoer/skills/<name>`. No root `package.json`, `codearts_cli.json`, or persistent permission was changed.
