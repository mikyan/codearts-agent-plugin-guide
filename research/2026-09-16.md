- 2026-09-16 检查了 GitHub Agent Skills Topic、上游 release/commit/docs 与当前 CodeArts Skills、Commands、Permissions 文档。GitHub 页面快照显示 Agentic Awesome 约 46.4k stars、6.8k forks；仓库当天仍活跃。
- 最新 release `v17.3.0` 于 2026-09-15 发布，tag 固定到 `69906dde999aaa0f3d173f0e3d5bcdb84c87a294`，目录含 2,122 个 Skill；本批不跟随浮动 `main`。
- 10 个候选此前均未出现在 research；按活跃度、实用性、单文件闭包、Windows 可执行性、无需凭据和可用只读合成输入选取。
- 10 个固定目录均只有一个 Markdown，无 manifest、lockfile、安装脚本、二进制或运行时依赖。AAS 代码为 MIT；原创非代码内容默认 CC BY 4.0。`api-analyzer` frontmatter 另标 MIT 及其上游许可证。
- 匿名 GitHub REST API 在本机共享出口触发限流，因此没有用空响应替代指标；流行度来自同日 GitHub 页面快照。

| 个人隔离 | 无项目覆盖的独立 consumer；用户 `skills/<name>` + `vendor/agentic-awesome-<name>` |

CodeArts 使用仅存在于验证进程内的非秘密 AK/SK 占位值配合显式外部模型；未持久化或打印凭据。每次调用使用独立 `KERNEL_DATA_DIR`，拒绝 Edit、Write、Delete、Bash、Read、Glob、Grep、Web 和外部目录访问。`agent-evaluation-reporting` 项目 B 的 Bash 被拒；`context-optimization` 项目 B 的 Write 被拒；`agent-harness-fault-injection` 项目 B 的三个 TodoWrite 成功事件使这些范围不满足“只有目标 Skill”门槛。

## 安全审查与安装方法

每个范围都从 GitHub 稀疏克隆固定 Commit 到独立 `vendor/agentic-awesome-<name>`，只把 `skills/<name>` 复制到 CodeArts 原生 Skills 目录。未运行上游 npm 脚本，未修改根 `package.json`、`codearts_cli.json`、持久权限或凭据。

静态审查覆盖全部 10 份将调用的 `SKILL.md`。正文中的网络服务、API、重试、子代理、故障注入、文件写入和仓库扫描示例均未执行；代表调用只使用合成事实并明确禁止其他工具。
