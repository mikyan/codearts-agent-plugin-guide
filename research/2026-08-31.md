## 上游、发现来源与安全审查

- 候选来自 [GitHub Agent Skills Topic](https://github.com/topics/agent-skills) 和活跃热门仓库 [mattpocock/skills](https://github.com/mattpocock/skills)。2026-08-31 快照为 242,450 Stars、20,611 Forks、443 Open issues/PRs，最近 Push 为 2026-08-24；固定 Commit `6654f6b60cd9d5be8b54c6fafe44346dabeb3b76`，最新 Release `v1.2.3`，MIT。
- 前九项都是内容型 Skill。只复制固定候选目录及明确的本地依赖目录；没有执行上游根 manifest、安装器、二进制、遥测、网络或凭据流程。
- 依赖闭包分别为：`implement + tdd + code-review`、`loop-me + grilling`、`retro + writing-for-agents`。其余候选复制自己的完整目录和引用文件；上游 `skills/engineering`、`skills/in-progress`、`skills/productivity` 父层级未带入 CodeArts 目标路径。
- `retro` 可能读取机器上的会话日志，本轮强制只读候选目录内的 `session-log.md`。`teach` 默认会检索外部可信资料，本轮把 `sources/http-status.md` 指定为唯一来源并禁止网络。`prototype` 禁止打开浏览器。
- `setup-pre-commit` 的正文要求安装没有版本号的 `husky lint-staged prettier`，随后执行 `npx husky init` 和 `npx lint-staged`，候选目录没有 lockfile 或固定包版本。依照“依赖必须固定且禁用未审查生命周期脚本”的门槛，本轮没有安装、加载或调用它，也没有用低质量替代流程凑数。

## 环境与隔离方法

- 运行前仓库为正确的 `mikyan/codearts-agent-plugin-guide` checkout，`main` 位于 `fe6ca61916ebebb90ebee08f54217f085d441d21`，工作树干净，`HEAD...origin/main` 为 `0 0`。
- 真实 CodeArts CLI 26.8.1：`%USERPROFILE%\.codeartsdoer\installers\codearts.cmd`；Windows 11 Build 26200；PowerShell 7.6.5；Git 2.53.0.windows.2；Node 24.14.1；npm 11.11.0；模型 `mimo/mimo-v2.5`。
- 当前进程使用非敏感 `CODEARTS_CLI_AK/SK` 占位值通过 CLI 前置检查，并显式选择已配置的外部模型。占位值从未持久化或写入证据。
- 每项先检查同名冲突，再分别安装到候选专属项目 A、从零创建的项目 B，以及 `~/.codeartsdoer/skills/<name>`。个人级调用目录没有同名项目 Skill。
- 每个已安装范围先运行 `codearts debug skill`，要求输出候选及所有依赖的准确绝对路径；随后运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`。需要文件或 Git 写入的流程使用 `--auto`，只允许操作隔离目录。
- 最终矩阵给 `implement`、`prototype` 每次 120 秒，其余候选每次 60 秒。超时记录为 `runExit=124` 并终止精确 CodeArts 子进程；不以已有文字或半成品自动升级为通过。一次早期无界 `implement` 探索调用被终止并完整回滚，不计入最终矩阵。
