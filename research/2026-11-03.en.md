# 2026-11-03: Ten CodeArts validations on Agentic Awesome v20.4.0

[简体中文](2026-11-03.md)

## Summary

This batch advanced ten candidates not previously covered under these slugs: `animation-performance`, `animation-vocabulary`, `apple-design`, `ask-sonner`, `find-animation-opportunities`, `mobile-native`, `pick-ui-library`, `remove-animations`, `show-the-change`, and `write-swift`. The source was pinned to Agentic Awesome `v20.4.0` at `1519f8199eb73d110ebc01f309e26c1868c8d502`.

Every candidate independently went through source-hash comparison, unique CodeArts discovery, a real `codearts run`, exact removal, and post-removal discovery in project A, a fresh project B, and user scope. Installation passed 30/30, discovery passed 30/30, and rollback passed 30/30. However, every `mimo/mimo-v2.5` call returned `400 Unsupported model mimo-v2.5` before any `skill` or other tool event. An independent `mimo/mimo-v2.5-pro` probe was also blocked by network policy before any tool event.

All ten results are therefore **Untested (environment blocked)**, not incompatibility findings. No guide or guide-index row was added.

## Rollback and publication decision

All 30 post-removal discovery checks excluded the former absolute path, and all ten user skill directories are absent. These non-secret files had identical hashes before and after the batch:

- `package.json`: `589A2F93D6B401FCCE4EDED58C4C477C3891C3B580796862C58ACB4E5D73A4E7`
- `codearts_cli.json`: `6F08A23430F657E3CBF75ABDCF1CB7A08FE88504F6FDC51BA31B6530386E2E23`
- Persistent permission file: `AC7831CD9D9FB18023BFD6C7778E71FF4A0DBCADAE60948189FBB0ECFDE2F447`

None of the ten passed every required gate: installation, CodeArts loading, core invocation, clean second-environment reproduction, and rollback. No formal guide was created. The complete process must be repeated after model routing recovers; discovery from this run cannot be promoted to a compatibility conclusion.
