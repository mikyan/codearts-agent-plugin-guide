## Discovery and pinned source

- Selection date: 2026-09-03. Candidates came from the [GitHub Agent Skills topic](https://github.com/topics/agent-skills), the [PM Skills repository](https://github.com/phuryn/pm-skills), and its releases, commits, issues, and documentation. The GitHub API snapshot showed 25,948 stars, 2,790 forks, and 42 open issues/PRs; the latest push was 2026-07-03.
- Upstream default-branch HEAD and latest release both resolve to [`18468a95b427e70e258b51389796367c6f684e7d`](https://github.com/phuryn/pm-skills/commit/18468a95b427e70e258b51389796367c6f684e7d), tagged `v2.1.0` and released 2026-07-03. The pinned tree contains 68 independent skills.
- The license is MIT. Each candidate contains only `SKILL.md`, with no co-located dependencies, lockfiles, binaries, install hooks, telemetry, or credential flow. The root `validate_plugins.py` and tests were neither copied nor executed.
- `market-sizing`, `customer-journey-map`, and `pricing-strategy` permit optional web research; `ab-test-analysis` and `cohort-analysis` can optionally run Python; several skills recommend saving Markdown. Smoke prompts supplied complete local facts and explicitly forbade network, scripts, and file writes. Any out-of-scope tool attempt remained a failure rather than receiving broader permission.
- Earlier batches covered ten other skills from this repository. This run selected ten remaining directories based on activity, common PM value, Windows safety, and auditable inputs, without repeating a prior research entry.

## Environment and isolation

- Real CodeArts CLI 26.8.1 at `%USERPROFILE%\.codeartsdoer\installers\codearts.cmd`.
- Windows 11 Pro build 26200; PowerShell 7.6.5; Git 2.53.0.windows.2; Node 24.14.1; npm 11.11.0.
- Model: `mimo/mimo-v2.5`. The parent process had no `CODEARTS_CLI_AK/SK`. Verification child processes received non-secret, non-persisted placeholders so CodeArts 26.8.1 could enter the configured external Provider; the Provider configuration still authenticated the model.
- Every candidate used an independent project A, independent project B, and user consumer. Project targets were `<project>/.codeartsdoer/skills/<name>` with pinned source at `<project>/.codeartsdoer/vendor/pm-skills-<name>`. User scope used matching `~/.codeartsdoer/skills/<name>` and isolated `vendor/pm-skills-<name>` paths.
- Each install stopped on a same-name collision, sparse-checked out the pinned commit, and copied only the candidate directory. No upstream `pm-*` parent hierarchy entered the native skill target, and no user-root manifest, model configuration, or credential changed.
- Each scope first used `codearts debug skill` to assert the exact absolute location, then invoked `codearts run -m mimo/mimo-v2.5 --format json`. No `--auto` was used. Each session had a 90-second limit; timeout killed only the exact CodeArts child process and counted as failure.

## Per-candidate results

1. **`ab-test-analysis` — Partial:** project B and user scope used only the target skill and completed conversion rates, relative lift, p-value, confidence interval, power check, and recommendation. After loading the skill, project A violated the prompt with Bash: a `python3 -c` attempt failed because Windows had no Python command, then another command read the date. The session timed out at 90 seconds without an acceptable final result. Core behavior did not reproduce across both projects, so there is no guide.
2. **`cohort-analysis` — Partial:** projects A/B completed three retention cohorts, maximum drops, three insights, and two follow-up studies. User scope loaded the skill, read the date, then tried to emit its report through a Bash here-document. PowerShell parsing failed and the session timed out at 90 seconds. User-scope core behavior failed, so there is no guide.
3. **`market-sizing` — Works:** all scopes used only one target skill call and completed boundaries, top-down and bottom-up estimates, TAM/SAM/SOM, reconciliation, confidence-labeled assumptions, and validation from supplied facts, without network access.
4. **`sql-queries` — Works:** all scopes generated PostgreSQL that correctly handled users created in the last 30 days, post-signup sessions, a five-session minimum, count, average duration, ordering, an index, and a read-only validation query. No database was connected or queried.
5. **`customer-journey-map` — Works:** all scopes covered the seven stages from Awareness through Advocacy, each with touchpoint, action, emotion, pain, and opportunity, followed by an aha moment, moment of truth, churn trigger, and three priorities.
6. **`user-personas` — Works:** all scopes built exactly three distinct personas from the three supplied clusters, each with JTBD, three pains, three gains, an unexpected insight, product fit, and a data gap.
7. **`interview-script` — Partial:** all scopes loaded the target skill and produced a 30-minute Mom Test text. Project B then tried to write `interview-script.md`; event `call_fcf626fd4e754efb87ea8131` was `write:error` / permission rejected, and no file existed. Because the upstream instruction requires saving Markdown and clean-project reproduction failed, there is no guide.
8. **`north-star-metric` — Works:** all scopes classified a Productivity Game, chose one customer-value North Star, assessed all seven criteria, and provided four measurable inputs with causal explanations.
9. **`pricing-strategy` — Works:** all scopes delivered a model, value metric, Free/Pro/University tiers, annual discount, three assumptions, three risks, and a thresholded ethical experiment, without live competitor research.
10. **`product-strategy` — Works:** all scopes covered all nine canvas sections, three trade-offs, a North Star plus quarterly OMTM, build-versus-partner capabilities, defensibility, three critical hypotheses, and a low-cost experiment for each.
