## Installation, discovery, and rollback method

Each executed candidate was copied from the pinned read-only source into a scope-specific `vendor/agentic-awesome-<name>`, then copied intact to the native CodeArts `skills/<name>` path. No upstream npm script, lifecycle script, or command from the Skill body was run. User-root `package.json`, `codearts_cli.json`, persistent permissions, and credentials were not edited.

Every scope first ran real `codearts debug skill`, parsed the JSON, and required exactly one match by candidate name and absolute `SKILL.md` location. It then ran a candidate-specific `codearts run -m mimo/mimo-v2.5 --format json`. After exact Skill and vendor deletion, a second diagnostic required zero matches for the former `name + location`.
