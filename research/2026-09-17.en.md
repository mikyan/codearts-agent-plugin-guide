## Discovery, version, and licenses

- On 2026-09-17 the run checked GitHub Agent Skills Topic, upstream release/commit/docs, and current CodeArts Skills and Commands documentation. Agentic Awesome had about 46.5k stars and 6.8k forks, with a push the previous day; GitHub still marked `v17.3.0` as Latest.
- Release `v17.3.0` was published on 2026-09-15 and pins commit `69906dde999aaa0f3d173f0e3d5bcdb84c87a294`; its catalog contains 2,122 Skills. This run did not follow floating `main`.
- All ten were absent from earlier research and were selected for utility, a one-file closure, Windows feasibility, no credential requirement, and a synthetic read-only representative task.
- Every pinned directory contained only `SKILL.md`: no manifest, lockfile, install/postinstall, binary, downloader, or runtime dependency. AAS code is MIT and original non-code content is CC BY 4.0 under `LICENSE-CONTENT`; `anti-deception` additionally declares MIT in frontmatter.

## Security review and installation method

Every scope copied the candidate from the pinned read-only source to its own `vendor/agentic-awesome-<name>`, then copied the complete candidate into native CodeArts `skills/<name>`. No upstream script, documented Git/Kubernetes/database/load command, user-root `package.json`, `codearts_cli.json`, persistent permission, or credential was executed or changed.

Each installed scope used real `codearts debug skill` and required the candidate name plus exact `SKILL.md` location, followed by candidate-specific `codearts run -m mimo/mimo-v2.5 --format json`. The first summary compared escaped Windows paths in raw debug JSON as ordinary strings and mechanically reported 30 `discovered=False` values. Parsing the same immutable JSON into objects and comparing exact `name + location` corrected all 30 to True. This was a harness assertion correction, not a candidate rerun.
