## 环境与隔离

- 真实 CodeArts CLI 26.8.1：`%USERPROFILE%\.codeartsdoer\installers\codearts.cmd`。
- Windows 11 专业版 Build 26200；PowerShell 7.6.5；Git 2.53.0.windows.2；Node 24.14.1；npm 11.11.0。
- 模型：`mimo/mimo-v2.5`。父进程没有 `CODEARTS_CLI_AK/SK`；验证子进程只设置未持久化的非秘密占位值，让 CodeArts 26.8.1 进入已配置外部 Provider，实际模型鉴权仍由 Provider 配置完成。
- 每个候选都使用独立项目 A、独立项目 B 与个人级 consumer。项目级目标为 `<项目>/.codeartsdoer/skills/<name>`，固定源码位于 `<项目>/.codeartsdoer/vendor/pm-skills-<name>`；个人级使用相同的 `~/.codeartsdoer/skills/<name>` 与独立 `vendor/pm-skills-<name>` 布局。
- 安装先检查同名冲突，再 sparse checkout 固定提交并只复制候选目录。没有把 `pm-*` 上游父目录带入 CodeArts 原生 Skill 目标，也没有修改用户根 manifest、模型配置或凭据。
- 每个范围先用 `codearts debug skill` 断言准确绝对路径，再用 `codearts run -m mimo/mimo-v2.5 --format json` 调用。未使用 `--auto`；单次上限 90 秒，超时只终止准确的 CodeArts 子进程并记为失败。

## 逐项结果

1. **`ab-test-analysis` — Partial：**项目 B 与个人级只调用目标 Skill，完成转化率、相对提升、p 值、置信区间、功效检查和建议。项目 A 在完成 Skill 后违反提示词调用 Bash：一次尝试 `python3 -c` 因 Windows 无 Python 命令而失败，另一次读取日期；会话最终在 90 秒超时且没有可验收最终文本。核心能力没有在两个项目都复现，不发布指南。
2. **`cohort-analysis` — Partial：**项目 A/B 都完成三组留存率、最大下降、三个洞察和两个后续研究。个人级完成 Skill 后额外读取日期，又尝试把结果通过 Bash here-document 输出；PowerShell 解析失败并在 90 秒超时。个人级核心流程失败，不发布指南。
3. **`market-sizing` — Works：**三范围都只调用一次目标 Skill，使用给定事实完成市场边界、top-down 与 bottom-up、TAM/SAM/SOM、差异解释、假设置信度和验证方案；没有联网。
4. **`sql-queries` — Works：**三范围均生成 PostgreSQL 查询，正确处理最近 30 天用户、注册后会话、至少 5 次聚合、平均时长、排序、索引建议与只读校验；未连接或执行数据库。
5. **`customer-journey-map` — Works：**三范围均覆盖 Awareness 到 Advocacy 七阶段，每阶段含触点、行为、情绪、痛点和机会，并给出 Aha Moment、Moment of Truth、Churn Trigger 与三个优先改进。
6. **`user-personas` — Works：**三范围都根据三组给定模式生成恰好三个独立画像，每个都有 JTBD、三个痛点、三个收益、意外洞察、产品契合度和数据缺口。
7. **`interview-script` — Partial：**三个范围都完成目标 Skill 并生成 30 分钟、符合 Mom Test 的文本。项目 B 随后尝试写入 `interview-script.md`，事件 `call_fcf626fd4e754efb87ea8131` 为 `write:error` / 权限拒绝，磁盘没有该文件。由于正文要求保存 Markdown 且干净项目复现失败，不发布指南。
8. **`north-star-metric` — Works：**三范围都判断为 Productivity Game，选择单一客户价值北极星，逐项覆盖七条标准，并给出四个可测量输入指标及因果解释。
9. **`pricing-strategy` — Works：**三范围都给出模型、价值计量单位、Free/Pro/University 三层、年度折扣、三个假设、三个风险，以及带阈值的伦理实验；没有实时竞品搜索。
10. **`product-strategy` — Works：**三范围都覆盖九区画布、三个明确取舍、北极星与季度 OMTM、构建/合作能力、防御性、三个关键假设及各自的低成本实验。
