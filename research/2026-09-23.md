## 许可证与安全审查

- 九个候选目录只有 `SKILL.md`；`anti-sycophancy` 另含已完整审阅的 `README.md`。固定目录没有 manifest、锁文件、install/postinstall、可执行脚本、二进制或下载器。
- 各候选 frontmatter 声明 MIT 或 CC0-1.0，并列出原始来源；Agentic Awesome 的代码为 MIT，聚合内容遵循 `LICENSE-CONTENT` 与原始许可证。
- `skill-security-audit` 的合成输入描述凭据、外传和删除能力，但测试没有安装被审计包、使用凭据、联网或执行代码，只验证只读风险推理。
- `logic-lens`、`recsys-pipeline-architect` 等正文会建议代码或测试；本轮禁止 Read、Write、Edit、Bash、网络、浏览器和外部目录，只允许从完整合成输入给出答案。
- 所有复制源先哈希；安装只把固定目录复制到 CodeArts 原生 `skills/<name>`。没有更改用户根 `package.json`、`codearts_cli.json` 或凭据。

## 安装、发现、调用与回滚方法

主验证为每个候选和作用域建立独立 vendor，再复制到 `.codeartsdoer/skills/<name>`。每次先运行真实 `codearts debug skill`，要求候选名与准确 `SKILL.md` 绝对路径唯一匹配；随后运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`，要求目标 Skill 完成事件和可观察核心结果。

两个接近发布门槛的候选又从 GitHub clone，sparse checkout `skills/<name>`，checkout 固定 Commit，再复制到原生目录。`andrej-karpathy` 6/6 次主/发布流均为唯一目标事件；`skill-security-audit` 的发布流个人级出现两个同名 completed 事件，因此取消指南。

删除前逐次核对目标绝对路径位于对应 `.codeartsdoer` 根下；只删除准确 Skill 与 vendor 目录。卸载后真实 `codearts debug skill` 不再包含原 `name + location`。
