## 结论摘要

本批实际推进 10 个此前未按该 slug 覆盖的候选：`harvey-specter`、`ios-flows`、`ios-review`、`keepmacawake`、`requirements-writing`、`tweetapi`、`zambo`、`skill-skill`、`bluebook-writing` 和 `story-bible-continuity`。固定来源为 Agentic Awesome `v20.3.0` / `fd12137a75dfe8bc309ababd3df8369b43872a5a`。

其中 7 项内容型 Skill 在项目 A、全新项目 B 和个人级三个范围独立完成源文件哈希比对、CodeArts 唯一发现、真实 `codearts run`、精确卸载和卸载后发现检查：21/21 安装、21/21 发现、21/21 回滚通过。但 21/21 次 `mimo/mimo-v2.5` 调用都在任何 `skill` 或其他工具事件前返回 `400 Unsupported model mimo-v2.5`；备用模型 `mimo/mimo-v2.5-pro` 的隔离探针也在工具事件前被网络策略阻止。

另外 3 项在执行前停止：`keepmacawake` 仅适用于 Apple silicon/macOS 26+，核心操作会改变系统睡眠状态并可能启动付费试用；`tweetapi` 的代表核心调用需要账户/OAuth 并消耗配额；`zambo` 会把数据发送到远程 MCP、可能写托管状态并产生公开回执或费用。本机没有适用平台或经授权的隔离账户，不能用纯文本问答冒充核心验证。

十项均为 **Untested（环境或安全边界阻塞）**，不是“不兼容”结论。本轮不新增 `guides/` 或指南索引。

1. 项目 A：复制固定候选目录到 `<A>/.codeartsdoer/skills/<候选>`，逐文件核对 SHA-256，运行 `codearts debug skill` 和候选专用 `codearts run -m mimo/mimo-v2.5 --format json ...`，删除精确目录，再做卸载后发现检查。
2. 项目 B：从全新空目录重复完整流程。
3. 个人级：确认没有项目同名覆盖后，复制到 `C:\Users\AI_BA\.codeartsdoer\skills\<候选>`，从独立干净目录重复发现、调用与回滚。
