# 2026-11-02: Ten CodeArts validations on Agentic Awesome v20.3.0

[简体中文](2026-11-02.md)

## Summary

This batch advanced ten candidates not previously covered under these slugs: `harvey-specter`, `ios-flows`, `ios-review`, `keepmacawake`, `requirements-writing`, `tweetapi`, `zambo`, `skill-skill`, `bluebook-writing`, and `story-bible-continuity`. The source was pinned to Agentic Awesome `v20.3.0` at `fd12137a75dfe8bc309ababd3df8369b43872a5a`.

Seven content-only skills independently went through source-hash comparison, unique CodeArts discovery, a real `codearts run`, exact removal, and post-removal discovery in project A, a fresh project B, and user scope. Installation passed 21/21, discovery passed 21/21, and rollback passed 21/21. However, every `mimo/mimo-v2.5` call returned `400 Unsupported model mimo-v2.5` before any `skill` or other tool event. An isolated probe of the configured alternative, `mimo/mimo-v2.5-pro`, was also blocked by network policy before any tool event.

Three candidates stopped before installation. `keepmacawake` only supports Apple silicon on macOS 26+ and its core behavior changes system sleep state and may begin a paid trial. A representative `tweetapi` call needs an account/OAuth and consumes quota. `zambo` sends data to a remote MCP service, can write hosted state, and can produce public receipts or charges. This machine had neither the applicable platform nor an authorized isolated account, and a text-only answer would not be representative core evidence.

All ten results are **Untested (environment or safety boundary blocked)**, not incompatibility findings. No guide or guide-index row was added.
