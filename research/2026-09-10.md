## 安全审查

### PM Skills 七项

七个固定候选目录都只有 `SKILL.md`，没有依赖清单、锁文件、生命周期脚本、二进制、下载器、遥测或本地资源。安装只稀疏检出固定 Commit，把单个候选目录复制到原生 `.codeartsdoer/skills/<name>`；vendor 独立可删，用户根 `package.json` 不变。

`draft-nda` 与 `privacy-policy` 属法律/合规草稿能力。测试只用虚构实体和合成事实，要求显式“非法律建议”、UNKNOWN 与法律复核标记；任何补造期限、控制或法律结论都判失败。

### Dazbo 三项安全停止

- `deploy-skills-in-antigravity`：核心流程运行未固定版本的 `npx skills`，写入 `~/.agents/skills` 与 `~/.gemini/config/skills.json`；其 Windows 迁移脚本会遍历全部源 Skill、删除同名目标并移动全部目录。无法把代表能力约束为单候选、可审计且精确回滚，停止在安装前。
- `install-gemini-code-review-action`：从浮动 `main` URL 动态下载 workflow/TOML，检查 GitHub CLI 登录，处理 `GEMINI_API_KEY`，并要求写 workflow、提交和推送远端。没有获批的隔离 GitHub 仓库与凭据边界，停止在安装前。
- `secrets-with-git-crypt`：上游明确要求 Unix-like 环境和 `git-crypt`；脚本可运行 `sudo apt-get`、初始化 Git 过滤器、改写 `.gitattributes`/`.gitignore`、复制秘密并导出或解锁外部密钥。本机是 Windows，且没有授权的测试密钥或 Unix 环境，停止在安装前。
