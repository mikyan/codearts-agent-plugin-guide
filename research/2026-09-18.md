## 许可证与安全审查

- Agentic Awesome 的代码和工具为 MIT；原创非代码内容由 `LICENSE-CONTENT` 明确为 CC BY 4.0，第三方例外由来源表管理。
- 7 个 SEO/AEO 目录只有一个 `SKILL.md`；`seo-aeo-content-quality-auditor` 另有一个 Markdown reference；`seo-aeo-schema-generator` 有 `SKILL.md` 和 10 个 JSON 模板。固定目录没有 manifest、锁文件、install/postinstall、二进制、下载器或遥测代码。
- `seo-aeo-orchestrator` frontmatter 为 `risk: critical`，正文包含写文件、部署、Search Console/Bing 和定期监控流程。本批只在全部文件、命令、网络和浏览器权限被拒绝时验证缺少项目路径的安全停止，未授权任何变更或外部动作。
- `youtube-transcript-skills` 的镜像目录只有 `SKILL.md`，原始仓库 `tubeagentkit/youtube-transcript-skills` 为 MIT，固定观察到 upstream Commit `341093772ead1d04f59dd54b46643e0b250910dc`。但每个核心 API 调用都必须向 `getyoutubetranscript.com` 发送 `YOUTUBE_TRANSCRIPT_API_KEY`；自动注册还会发送用户邮箱和验证码。本轮没有获准凭据或隔离账号，因此执行前停止。

## 安装、发现与回滚方法

每个已执行候选都从固定只读来源复制到作用域专属 `vendor/agentic-awesome-<name>`，再复制完整候选目录到 CodeArts 原生 `skills/<name>`。没有运行上游 npm 脚本、生命周期脚本或正文中的外部命令，也没有修改用户根 `package.json`、`codearts_cli.json`、持久权限或凭据。

每个作用域先运行真实 `codearts debug skill`，把 JSON 解析后按候选名称与准确 `SKILL.md` 绝对路径要求唯一匹配；随后运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`。删除精确 Skill 和 vendor 目录后再次运行诊断，要求原 `name + location` 为零。
