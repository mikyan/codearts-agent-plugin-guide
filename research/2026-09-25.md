## 批次结论

本批实际推进 10 个此前未覆盖的 `SKILL.md` 候选，固定到 `sickn33/agentic-awesome-skills` release `v18.4.0` 与 Commit `7b534bc15d833baf3bc98b3ca4fb23eda48342bb`。其中 6 项是该 release 新增项，另外 4 项来自同一固定快照的天气数据与 Agent 记忆主题。

10 项都完成独立安全审查、项目 A、全新项目 B、无项目同名覆盖的个人级安装、真实 CodeArts 发现、代表调用和精确回滚。30/30 个安装态被 `codearts debug skill` 从准确绝对路径发现；30/30 个 `codearts run` 退出 0，并且都只有一个目标 `skill:completed` 事件；30/30 个安装目标精确移除，卸载后不再从原路径发现。

人工语义审计后，只有 `weather-data-lifecycle-management` 同时通过主验证与远程克隆发布流程的两个项目、个人级、核心语义和回滚门槛，结论为 **Works** 并创建正式双语指南。其余 9 项为 **Partial** 或 **Adapter Required**：它们虽然能安装和加载，但存在未执行真实下载/后端操作、计算错误、补造输入、跨环境语义错误，或缺少 CodeArts 原生实现。

## 许可证与安全审查

- 9 个候选目录只有一个 `SKILL.md`；`agent-memory-discipline` 另含 `references/entry-format.md`。全部固定目录都已完整审阅并生成文件 SHA-256 清单。
- 目录没有 manifest、锁文件、install/preinstall/postinstall、可执行脚本、二进制、下载器或候选级遥测。本批没有运行候选示例中的 AWS、HTTP、数据库、仪表板或安装命令。
- AAS 原创非代码内容默认采用 CC BY 4.0，代码与工具采用 MIT；第三方来源声明优先。`agent-memory-discipline` 明确为 CC0-1.0；`memory-systems` 原始仓库为 MIT；HAM 原始仓库为 MIT，但原始 README 明确“Claude Code only”。
- 所有代表调用使用内联合成数据，并通过独立临时权限文件拒绝 Write/Edit/Delete/Bash/Read/Web/Browser。没有访问真实天气数据、云凭据、记忆后端、用户会话或生产缓存，也没有删除真实文件。
- 安装只使用固定候选目录、CodeArts 原生 `.codeartsdoer/skills/<name>` 与独立可删除的 `vendor/agentic-awesome-<name>`。没有修改用户根 `package.json`、`codearts_cli.json`、持久权限或凭据。

## 安装、发现、调用与回滚方法

主批每个候选独立执行：固定源目录复制到作用域内 vendor，再复制到原生 Skills；运行真实 `codearts debug skill` 要求准确 `name + SKILL.md` 绝对路径唯一匹配；运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`；保存 JSONL、call ID 和最终文本并人工审计；在第二项目和个人级从零重复；验证绝对删除目标后只删除准确 Skill 与 vendor，再次运行真实发现诊断。

唯一通过候选又执行了指南一致的发布流程：每个范围从 GitHub `v18.4.0` 重新稀疏克隆，核对完整 Commit，复制到原生 Skill 目录，重复调用与回滚。`weather-data-reproducibility` 也进入该复验，但因发布项目 A 补造值而被撤回。

一次排除的测试基础设施失败发生在发布复验开始时：PowerShell 函数参数名与自动变量冲突，使 `codearts debug skill` 未收到参数并进入 TUI。该临时项目没有完成候选调用，修正参数名后在新目录从零重跑，未将其计入任何候选结果。
