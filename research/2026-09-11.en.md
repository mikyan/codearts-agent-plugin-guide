## Security and installation

The ten pinned directories contain eleven Markdown files in total and no dependency manifest, lockfile, lifecycle script, binary, downloader, or telemetry. Installation used sparse checkout at the fixed commit, copied only `skills/<name>` to native `.codeartsdoer/skills/<name>`, and kept a separately removable `vendor/agentic-awesome-<name>`. The user root manifest was untouched.

`ui-lint` contains read-only grep examples, but this batch supplied complete inline JSX and denied shell execution. Optional UIZZE, MCP, and `npx` paths in `anti-ui-slop` were not used. `read-all-adrs` read two synthetic ADRs only; its user run repeated the reads but emitted no write, shell, or network event.
