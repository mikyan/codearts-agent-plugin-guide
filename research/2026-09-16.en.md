## Discovery, version, and licensing

- On 2026-09-16, candidate discovery covered the GitHub Agent Skills topic, upstream release/commit/docs, and current CodeArts Skills, Commands, and Permissions documentation. The GitHub page snapshot showed about 46.4k stars and 6.8k forks, with same-day activity.
- The latest release, `v17.3.0`, was published on 2026-09-15 and pinned to `69906dde999aaa0f3d173f0e3d5bcdb84c87a294`; its catalog contains 2,122 Skills. This batch did not follow floating `main`.
- All ten candidates were new to research and selected for utility, a one-file closure, Windows suitability, no credential requirement, and a bounded read-only synthetic test.
- Every pinned directory contains one Markdown file and no manifest, lockfile, install script, binary, or runtime dependency. AAS code is MIT; original non-code content defaults to CC BY 4.0. `api-analyzer` additionally declares MIT and its source license in frontmatter.
- Anonymous GitHub REST calls hit a shared-egress rate limit, so empty API fields were not reported as metrics; popularity uses the same-day GitHub page snapshot.

## Security review and installation

Every scope sparse-cloned the pinned GitHub commit into a dedicated `vendor/agentic-awesome-<name>` and copied only `skills/<name>` into native CodeArts Skills. No upstream npm script ran, and root `package.json`, `codearts_cli.json`, persistent permissions, and credentials were untouched.

Static review covered all ten invoked `SKILL.md` files. Network services, APIs, retries, sub-agents, fault injection, writes, and repository-scan examples in the prose were not executed. Representative calls used synthetic facts and explicitly prohibited other tools.
