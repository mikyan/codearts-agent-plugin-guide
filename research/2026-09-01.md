- `migrate-to-shoehorn` 的正文命令未固定版本。本轮先审查 npm 元数据，再固定 `@total-typescript/shoehorn@0.1.2`，使用 `npm install --ignore-scripts --no-audit --no-fund`。`setup-ts-deep-modules` 固定 `dependency-cruiser@18.2.0` 与 `typescript@5.9.2`，同样禁用生命周期脚本；其本地 `dependency-cruiser.config.cjs` 与 `codebase-design` 依赖一并复制。
- `git-guardrails-claude-code` 的 Bash 脚本依赖 `jq`/`grep` 和 Claude Code `PreToolUse`，本轮不执行脚本、不创建 `.claude` 配置，只验证内容加载并确认它不是 CodeArts 原生 Hook。
- `claude-handoff` 会把脱敏摘要交给新的外部 `claude --bg` 进程；`implement-spec` 会创建草稿 PR、多个分支/工作树并调度实现、合并与评审代理。这些副作用超出隔离的只读/本地写入边界，因此两项没有安装或调用。
- `create-md-from-browsermcp-snapshot` 的正文强制要求 BrowserMCP 与 `browser_snapshot`。环境没有该 MCP；其 Python 解析器已逐行审查，但按上游守卫不得绕过前置条件直接运行。

- 运行前确认当前目录是 `mikyan/codearts-agent-plugin-guide` 的正确 checkout；干净 `main` 位于 `30259bf4c50debfd4603a617ce595868b033256d`，`HEAD...origin/main` 为 `0 0`，随后执行了 fetch 且无需快进。

- 进程使用非敏感 `CODEARTS_CLI_AK/SK` 占位值通过 CLI 前置检查，并显式选择已配置的外部模型。占位值未持久化、未进入研究文件或 Git。
- 8 个可安全运行的候选分别安装到候选专属项目 A、从零创建的项目 B，以及 `~/.codeartsdoer/skills/<name>`。个人级调用目录没有同名项目 Skill；同名冲突检查在复制前完成。
- 每个范围先运行 `codearts debug skill` 并断言准确绝对路径，再运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`。需要隔离文件写入的 5 项使用 `--auto`；只读或应停止的 3 项不使用 `--auto`。单次运行上限为 90 秒，超时记为 `runExit=124` 并终止精确 CodeArts 子进程。
- 依赖安装只发生在候选夹具目录；用户根 `package.json`、`codearts_cli.json` 和凭据均未修改。
