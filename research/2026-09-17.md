## 安全审查与安装方法

每个范围都从固定只读来源复制候选到独立 `vendor/agentic-awesome-<name>`，再复制完整候选目录到 CodeArts 原生 `skills/<name>`。没有运行上游脚本、文档中的 Git/Kubernetes/数据库/负载命令，也没有修改用户根 `package.json`、`codearts_cli.json`、持久权限或凭据。

每个安装先用真实 `codearts debug skill` 要求候选名称与准确 `SKILL.md` 绝对路径；随后运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`。最初汇总脚本把 debug JSON 中转义后的 Windows 路径当普通字符串比较，机械地产生 30 个 `discovered=False`；随后把 JSON 解析为对象并按 `name + location` 精确比较，30/30 均为 True。这是测试夹具断言修正，不是重跑候选，也没有改变原始证据。
