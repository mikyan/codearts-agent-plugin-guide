## 环境与隔离

| 项目 | 值 |
| --- | --- |
| CodeArts CLI | 26.8.1，真实 `codearts.exe` |
| OS | Windows 11 Build 26200 |
| PowerShell | 7.6.6 |
| Git | 2.53.0.windows.2 |
| Node.js / npm | 24.14.1 / 11.11.0 |
| 模型 | `mimo/mimo-v2.5` |
| 项目隔离 | `.tmp/v915/runs/<candidate>-a|b`；前两项证据在长路径批次目录 |
| 个人隔离 | 无项目覆盖的独立 consumer；用户 `skills/<name>` + `vendor/agentic-awesome-<name>` |

CodeArts 使用仅存在于进程内的非秘密 AK/SK 占位值配合显式外部模型；未持久化或打印凭据。每次调用使用工作区独立 `KERNEL_DATA_DIR`，拒绝 Edit、Write、Delete、Bash、Read、Glob、Grep、Web 与外部目录访问。

首次运行在长 Windows 路径下的 `ask-questions-if-underspecified` 克隆于安装前失败，因此缩短根目录后从零执行；该失败不计候选结果。`backend-dev-guidelines` 个人级首次克隆因 Git 网络进程卡住而在 Skill 复制前终止，残留精确移出用户 vendor、删除后再从零执行。两次均是安装基础设施恢复，不是语义失败后的重试。

## 安全审查与安装方法

所有候选复制闭包均无清单、锁文件、install/postinstall、可执行脚本、二进制、下载器或遥测。`backend-dev-guidelines` 含 12 个 Markdown（138,774 字节），`code-review-excellence`、`debugging-strategies`、`error-handling-patterns`、`test-driven-development` 各含 2 个 Markdown；其余各 1 个。正文中的网络、部署、npm、写入和组合 Skill 建议未执行。

每个范围都从 GitHub 稀疏克隆固定 Commit 到独立 `vendor/agentic-awesome-<name>`，只把 `skills/<name>` 复制到 CodeArts 原生 Skills 目录。未修改根 `package.json`、`codearts_cli.json` 或持久权限。
