## Candidate results

1. **`analyze-feature-requests` — Partial:** Project A/B timed out after the target Skill completed and produced no final text. User scope produced themes, a top three, alternatives, and tests, but calculated LMS import's `0.95 × (1 − 0.20)` as `0.190`; the correct value is `0.760`, while the text still called it the highest raw score. The prioritization evidence is unreliable.
2. **`ansoff-matrix` — Partial:** All three scopes discovered and completed the target Skill event, but all timed out before any final four-quadrant, priority, or roadmap text. This proves loading, not core behavior.
3. **`beachhead-segment` — Partial:** Project A timed out after completing the Skill. Project B added a `todowrite` call and timed out. User scope produced two completed Skill events plus a `skill:error`, with no unique stable target call or final result.
4. **`business-model` — Partial:** User scope used only the target Skill and completed all nine blocks, illustrative unit economics, three risks, and tests. Projects A/B timed out after the Skill event, so clean-project reproduction failed.
5. **`growth-loops` — Partial:** Project A completed five loop scores, primary/secondary loops, coefficient, privacy guardrails, a 30/60/90-day plan, and stop thresholds. Project B timed out after two extra `todowrite` calls; user scope timed out after completing the Skill.
6. **`ideal-customer-profile` — Partial:** Projects A/B both completed the primary ICP, high-value subset, profile, behaviors, JTBD, pains, journey, messaging, disqualifiers, and evidence gaps, so second-project reproduction passed. User scope timed out after completing the Skill, failing the intended cross-project scope.
7. **`market-segments` — Partial:** Project B completed four distinct segments, ranking, and a research priority. Project A and user scope timed out after completing the Skill and produced no final text.
8. **`pestle-analysis` — Partial:** Project B and user scope completed three factors in all six categories plus the top five, responses, indicators, contingencies, and research needs. Project A timed out after the Skill; the second project cannot replace a failed first project.
9. **`prioritization-frameworks` — Partial:** Project A completed Opportunity Score and RICE-like calculations, ranking, framework comparisons, and sensitivity analysis. Project B and user scope timed out after completing the Skill. Project A also treated supplied Effort directly as ICE Ease, showing that the ICE comparison needs an explicit conversion rule.
10. **`value-prop-statements` — Partial:** Automated literal checks passed in all three scopes, but manual semantic review rejected publication. The outputs added capabilities the user never supplied, including “no analytics/no account required,” “one-click import/zero-leak assurances,” and “photo input/intelligent algorithms.” This conflicts with deriving copy only from the existing proposition and flagging overclaims. Complete markers do not establish core quality.
