## 许可证与安全审查

- 所有候选固定到同一不可变 Commit。上游根代码与工具为 MIT；原创非代码内容默认 CC BY 4.0，第三方候选以自身 frontmatter 与捆绑许可证优先。
- `uxkin-research`、`equibles`、`url-to-markdown`、`kernel-prompt`、`skeleton-first`、`changelog-entry` 都只有一个 `SKILL.md`。`what-could-break` 另含 MIT 许可证；`business-email-template` 另含一个 Markdown 参考；`reverse-engineer-anything` 含五个 Markdown 参考；`tastegate` 含一个 Python 脚本、五个参考/许可证文件。
- 候选目录没有 package manifest、锁文件、install/preinstall/postinstall、候选级遥测或捆绑二进制。复制安装不运行 npm/pip 生命周期。
- `reverse-engineer-anything` 正文包含浮动 `npx rea-agents@latest`，本轮明确禁止执行；`tastegate` 建议首次安装 Playwright/Chromium，本轮不执行未固定安装，脚本只验证缺依赖时的真实失败。两项都没有达到正式指南门槛。
- `equibles` 没有读取环境变量、API key 或账户；`uxkin-research` 没有连接 UXKIN MCP。`url-to-markdown` 只访问公开 `https://md.replynodes.com/example.com`，输入内容按不可信数据处理。
- 项目/个人安装均使用 CodeArts 原生 `.codeartsdoer/skills/<name>` 和独立 `vendor/agentic-awesome-<name>`；没有修改用户根 `package.json`、`codearts_cli.json`、持久权限或凭据。

## 安装、发现、调用与回滚方法

主批对每项独立执行：把固定候选复制到作用域内 vendor，再复制到原生 Skills；运行 `codearts debug skill`，要求准确 `name + SKILL.md` 绝对路径唯一匹配；运行候选专用 `codearts run -m mimo/mimo-v2.5 --format json`；保存 JSONL、call ID 和最终文本并人工审计；在第二项目和个人级从零重复；核对绝对删除目标后仅删除准确 Skill 与 vendor，并再次运行发现诊断。

初步通过的 4 项又按拟发布指南从 GitHub `v19.4.0` 远端 tag 在每个范围重新稀疏克隆，核对完整 Commit，复制、调用、回滚。`changelog-entry` 因发布项目 B 违反“只输出条目”而撤回，未创建指南。`what-could-break` 另做精确指南布局复验：第一次从烟雾子目录启动时项目 A/B 出现 `skill:error`，整组排除；修正为从项目根启动、只检查子目录后，项目 A/B/个人级 3/3 通过。

开始正式主批前发现 2026-10-10 中断运行遗留个人级 `reverse-engineer-anything`。其 6 个文件的路径、字节数、SHA-256 和时间戳均与旧自动化清单一致；两个精确 Skill/vendor 目录移入自动化隔离区后才从新证据根重跑。本次首次受污染的项目 A/B 结果全部排除。
