## License and security review

- Nine candidate directories contained only `SKILL.md`; `anti-sycophancy` also contained a fully reviewed `README.md`. No pinned directory had a manifest, lockfile, install/postinstall hook, executable script, binary, or downloader.
- Candidate frontmatter declared MIT or CC0-1.0 and named the original source. Agentic Awesome code is MIT, while catalog content follows `LICENSE-CONTENT` and original licenses.
- The synthetic input for `skill-security-audit` described credentials, exfiltration, and deletion, but the test installed no audited package, used no credential, accessed no network, and ran no code. It exercised read-only risk reasoning only.
- Bodies such as `logic-lens` and `recsys-pipeline-architect` can suggest code or tests. This run denied Read, Write, Edit, Bash, network, browser, and external-directory access and required answers from complete synthetic inputs.
- Copy sources were hashed before installation. Installation copied only pinned directories to native CodeArts `skills/<name>` and never changed the user-root `package.json`, `codearts_cli.json`, or credentials.

## Installation, discovery, invocation, and rollback method

The main run created a scope-specific vendor copy for every candidate and copied it to `.codeartsdoer/skills/<name>`. Each scope first ran real `codearts debug skill`, requiring one exact name and absolute `SKILL.md` path, then ran a candidate-specific `codearts run -m mimo/mimo-v2.5 --format json` and required a completed target Skill event plus an observable representative result.

The two candidates closest to publication were cloned from GitHub, sparse-checked out at `skills/<name>`, checked out at the pinned commit, and copied into the native directory. `andrej-karpathy` emitted one target event in all six main/publication calls. The user publication flow for `skill-security-audit` emitted two completed same-name events, so its guide was withheld.

Before removal, every absolute target was checked to be inside its intended `.codeartsdoer` root. Only the exact Skill and vendor directories were removed. Real post-removal `codearts debug skill` excluded every former `name + location`.
